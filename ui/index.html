    单独安装程序 / 修改安装位置

    已有程序可直接在“设置”中填写目录。以下操作只在点击对应按钮后执行。

    Node.js LTS

    使用 winget 安装 Node.js LTS，安装后自动刷新环境并检测 npm，通常无需重启电脑。若检测未通过，请重新打开启动器；未安装 winget 时可使用官网 MSI。

    QQ NT

    自动从 QQ 官网获取当前版本安装包并打开安装器。安装完成后在“设置”中选择实际 QQ.exe。账号登录在 QQ 内完成。

    SnowLuma Windows 完整版

    自动获取官方最新 Windows 完整包，校验后解压到新目录并保存路径。首次登录密码请在启动日志中查看。

    尚未选择安装包

    Koishi 项目

    自动运行 Koishi 官方脚手架创建项目并安装依赖，完成后保存路径。已有目录不会被覆盖。

    基础插件与 HDSI

    安装 HDSI 时会自动依次补齐完整 Console 模块、OneBot 适配器及 SQLite，再安装所选 beta 或 .tgz 包。任一步失败即停止；也可单独补齐基础插件。

    安装或更新 HDSI 插件

    已安装版本：尚未检测

    推荐在线检查 npm beta 版本。也可从 GitHub 下载 .tgz 安装包后拖入，Gitee 作为备用。

    将 HDSI 的 .tgz 文件拖到这里

    也可以选择文件。会读取真实包名、版本与校验值。

    安装命令与校验信息

    请先停止 Koishi。安装前自动备份配置与依赖清单；完成后手动启动服务。

    配置完成后

    1. 打开 QQ，登录机器人账号。
    2. 启动 SnowLuma，在 WebUI 中注入 QQ，并按教程设置 WebSocket 服务。
    3. 启动 Koishi，确认连接 Token、端口与 SnowLuma 一致。
    4. 在聊天中运行 interlude.doctor 检查，再开始故事。
