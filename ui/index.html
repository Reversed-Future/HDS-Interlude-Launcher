                首次安装 · 按步骤准备环境
                
    
                  已有程序可直接在“设置”中填写目录。以下操作只在点击对应按钮后执行。
                
    
                
    01 / Node.js LTS
    
                
    
                  使用 winget 安装 Node.js LTS，安装后自动刷新环境并检测
                  npm，通常无需重启电脑。若检测未通过，请重新打开启动器；未安装
                  winget 时可使用官网 MSI。
                
    
                
    
                  
                  
                  
                
    
                
    02 / QQ NT
    
                
    
                  自动从 QQ
                  官网获取当前版本安装包并打开安装器。安装完成后在“设置”中选择实际
                  QQ.exe。账号登录在 QQ 内完成。
                
    
                
    
                  
                  
                
    
                
    03 / SnowLuma Windows 完整版
    
                
    
                  自动获取官方最新 Windows
                  完整包，校验后解压到新目录并保存路径。首次登录密码请在启动日志中查看。
                
    
                
    
                  
                
    
                
    尚未选择安装包
    
                
                
    
                  
                
    
                
                
    
                  
                  
                
    
                
    04 / Koishi 项目
    
                
    
                  自动运行 Koishi
                  官方脚手架创建项目并安装依赖，完成后保存路径。已有目录不会被覆盖。
                
    
                
                
    
                  
                
    
                
                
    
                  
                
    
                
    05 / 基础插件与 HDSI
    
                
    
                  安装 HDSI 时会自动依次补齐完整 Console 模块、OneBot 适配器及
                  SQLite，再安装所选 beta 或 .tgz
                  包。任一步失败即停止；也可单独补齐基础插件。
